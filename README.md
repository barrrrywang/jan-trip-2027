# 一月，两种慢法

从成都出发的两个慢节奏方案：丽江玉龙雪山 4 天，九寨沟 3 天。都不自驾。

把 `index.html`、所有 `.jpg` 和本说明放到网站根目录即可，例如 GitHub Pages 仓库根目录。用浏览器直接打开 `index.html` 也可以。
